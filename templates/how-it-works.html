AI Detection Pipeline

Our Deep Fake Image Detection system uses a deep learning model based on Vision Transformer (ViT). When a user uploads an image, the system first preprocesses the image by resizing and converting it into tensors. The image is then passed into the trained model, which analyzes patterns, textures, and inconsistencies often found in deepfake images.


The model generates prediction scores and determines whether the image is real or fake. Finally, the system displays the prediction along with a confidence score to the user.
