AI Model Information

Understanding the technology behind deepfake detection

Model Used

This system uses a Vision Transformer (ViT) model for image classification. The model analyzes image patterns to detect whether the image is real or generated using deepfake technology.

Dataset

The model was trained on a dataset containing both real and deepfake images to learn visual differences between authentic and manipulated images.

Technologies Used

Python, Flask, HuggingFace Transformers, PyTorch, Vision Transformer (ViT), HTML, CSS, and JavaScript.

Model Accuracy

The trained model achieves high accuracy in detecting fake images by analyzing image textures, patterns, and inconsistencies.
